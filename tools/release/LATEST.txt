# What the latest update brings, shown by the game when it offers the update (make_release.py writes it into the
# update release's update.json). Only this update's changes: written anew for each update. One section a language

[en]
- Volume settings (PC Settings, General): Volume, Music, Voices and Effects.
- Remastered Interface (PC Settings, Graphics): the HUD, menus and text on their own, apart from the world's Remastered Textures.
- God Mode turned off takes effect at once, not at the next mission.
- A crash just after finishing a mission (Airfield Ambush) is gone.
